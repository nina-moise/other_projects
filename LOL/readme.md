# Разработка дашборда аналитики League of Legends
Проект реализован в рамках **Яндекс Мастерской**. Даты проекта: 29.05.2026-01.07.2026

## Заказчик
Аналитический отдел киберспортивного клуба.
 
## Цель проекта 
Разработать интерактивный дашборд, отображающий статистику матчей, игроков и чемпионов League of Legends за текущий месяц для регионов Европа и США. Дашборд должен быть реализован на Python с использованием официального API Riot Games.

## Техническое задание

## Задачи проекта
1. **Extract**. Извлечение данных с использованием официального API Riot Games. 
2. **Transform**. Обработка извлеченных данных.
3. **Load**. Разработка интерактивного дашборда для визуализации результатов.

## Использованные технологии и навыки
* **Data Sourcing**: Интеграция с официальным **Riot Games API** (отправка запросов, обработка JSON, обход лимитов).
* **Backend & DB**: Python (Pandas, Requests, Gc, Logging), Supabase (PostgreSQL), SQLAlchemy.
* **Frontend**: Streamlit, Plotly.
* **Jupyter Notebook**, **DBeaver**

## Этап 2. Transform & Load

Выполнен Этап T (Transform) в архитектуре ETL проекта:

1. **Предобработка данных (Python / Pandas)**: Полученные на этапе извлечения «сырые» данные в формате CSV очищены от дубликатов, в них обработаны пропуски, осуществлено приведение типов к нужным форматам. Финальные очищенные данные сохранены в промежуточные датафреймы.

Выполнена этап L (Load) в архитектуре ETL проекта - загрузка в хранилище.
   
2. **Миграция в СУБД**: Очищенные структурированные данные перенесены в реляционные таблицы облачной базы данных Supabase (PostgreSQL) (ресурс https://supabase.com) для долгосрочного структурированного хранения.
3. **Агрегация и расчет KPI (SQL Views)**: С помощью SQL-скриптов на стороне базы данных сформированы витрины данных (представления). В них заранее рассчитаны сложные игровые метрики (KDA, индекс агрессии игроков, винрейты сторон по регионам), что позволяет минимизировать нагрузку на дашборд и обеспечить мгновенную загрузку интерфейса.

## Бизнес-ценность проекта и аналитические выводы 

Разработанная платформа представляет собой полноценный аналитический инструмент для исследования игровой экосистемы League of Legends на серверах Европы и США за май 2026 года. Проект решает задачи сбора сырых данных из внешнего API и их трансформации в готовые управленческие инсайты для геймдизайнеров, киберспортивных аналитиков и геймеров.

### Ключевая ценность разработанных модулей

1. **Раздел «Матчи»**:
   * **Мониторинг вовлеченности**. Графики **"Количество матчей в день"** и **"Количество уникальных игроков в день (DAU)"** позволяют отслеживать удержание аудитории (Retention) в течение мая 2026 года, оценивать стабильность интереса к игре (вовлеченность), влияние дней недели (выходные против будней) или внутриигровых событий на онлайн.
   * **Баланс сторон**. Диаграмма **«Общий баланс сторон (Win Rate)»** визуализирует процент побед Синей команды против Красной. Позволяет геймдизайнерам отследить дисбаланс в игре (в идеальном состоянии он должен быть 50/50).
   * **Зависимость исхода игры от времени**: Интерактивная пузырьковая диаграмма корреляции сопоставляет конкретную минуту матча, фактический винрейт команды и объем игр, завершившихся на этой минуте. Позволяет понять «киберспортивную зрелость» региона. Например: склонны ли игроки в низших лигах сдаваться на ранних минутах, или большинство игр затягивается в лейт-стадию (более 40 минут).
   * Графики **Распределение длительности матчей по патчам** и **"Индекс кровавости по версиям игры (KPM)"** позволяют отслеживать влияние обновлений на темп игры и баланс, выявляя аномалии в длительности и агрессивности матчей.

2. **Раздел «Игроки»**:
   * **"Средний KDA игрока лиги"** и **"Средний K/A игрока лиги"** позволяют увидеть эффективность ведения боя, стиль игры в разных рангах и серверах, а также "токсичность" атмосферы игры для киберспортивных команд. 
   * График **«Распределение очков по лигам|регионам»** позволяет оценить cилу и активность регионов и лиг:
     - сравнение медианы LP в топовых лигах (Master, Grandmaster, Challenger) между серверами (EUW, NA);
     - выявление регионов и лиг с перенасыщенным «топом», где для удержания ранга требуется аномально высокое количество очков;
     - порог входа в киберспорт - точный барьер (в LP), который необходимо преодолеть игроку в конкретном регионе, чтобы попасть в поле зрения профессиональных команд;
     - плотность конкуренции между игроками.
   * **"Топ-10 игроков по LP, Win Rate, Количеству игр"** - классический лидерборд, позволяет увидеть портреты идеальных игроков и определить, какая стратегия ведения игры приводит к вершине рейтинга.
   * **"Поиск игрока по его имени"** -  интерактивный инструмент индивидуальной диагностики агрегирует ключевые метрики конкретного геймера в единый профиль:
     - позволяет моментально оценить текущую игровую форму геймера: его сильные стороны, стабильность (через KDA) и общую эффективность (Win Rate), стиль игры (через индекс агрессии KA, приоритетного чемпиона и позиции);
     - инструмент для анализа соперников и меты сервера. 
    
3. **Раздел «Чемпионы»**
   
**Анализ игровой меты и баланса ()**:
   * **Карта игровой меты** визуализирует корреляцию между популярностью чемпионов (`Pick Rate`) и их эффективностью (`Win Rate`) . Это главный инструмент для выявления несбалансированных (Overpowered) персонажей, требующих ослабления, а также «скрытой меты» — эффективных, но редких чемпионов в руках узкоспециализированных игроков .
   * **Кривая силы чемпионов** по времени игры математически разделяет персонажей на доминирующих в ранней игре (Early-game) и гипер-персонажей поздней стадии (Late-game scaling), помогая командам выстраивать победные стратегии на стадии драфта .
   * **Диаграмма распределения по позициям** наглядно демонстрирует профильные роли чемпионов и оценивает их «флекс-потенциал» (универсальность использования на разных линиях), что критически важно для тактического запутывания оппонента в матчах.
