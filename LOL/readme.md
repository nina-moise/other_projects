# Разработка дашборда аналитики League of Legends
Проект реализован в рамках **Яндекс Мастерской**. Даты проекта: 29.05.2026-26.06.2026

## Заказчик
Аналитический отдел киберспортивного клуба.
 
## Цель проекта 
Разработать интерактивный дашборд, отображающий статистику матчей, игроков и чемпионов League of Legends за текущий месяц для регионов Европа и США. Дашборд должен быть реализован на Python с использованием официального API Riot Games.

## Техническое задание

## Задачи проекта
1. **Extract**. Извлечение данных с использованием официального API Riot Games. 
2. **Transform**. Обработка извлеченных данных.
3. **Load**. Разработка интерактивного дашборда для визуализации результатов.

## Использованные технологии и навыки
* **Data Sourcing**: Интеграция с официальным **Riot Games API** (отправка запросов, обработка JSON, обход лимитов).
* **Backend & DB**: Python (Pandas, Requests, Gc, Logging), Supabase (PostgreSQL), SQLAlchemy.
* **Frontend**: Streamlit, Plotly.
* **Jupyter Notebook**, **DBeaver**

## Этап 2. Transform & Load

Выполнен Этап T (Transform) в архитектуре ETL проекта:

1. **Предобработка данных (Python / Pandas)**: Полученные на этапе извлечения «сырые» данные в формате CSV очищены от дубликатов, в них обработаны пропуски, осуществлено приведение типов к нужным форматам. Финальные очищенные данные сохранены в промежуточные датафреймы.

Выполнена этап L (Load) в архитектуре ETL проекта - загрузка в хранилище.
   
2. **Миграция в СУБД**: Очищенные структурированные данные перенесены в реляционные таблицы облачной базы данных Supabase (PostgreSQL) (ресурс https://supabase.com) для долгосрочного структурированного хранения.
3. **Агрегация и расчет KPI (SQL Views)**: С помощью SQL-скриптов на стороне базы данных сформированы витрины данных (представления). В них заранее рассчитаны сложные игровые метрики (KDA, индекс агрессии игроков, винрейты сторон по регионам), что позволяет минимизировать нагрузку на дашборд и обеспечить мгновенную загрузку интерфейса.

**Результат:**

## Бизнес-ценность проекта и аналитические выводы 

Разработанная платформа представляет собой полноценный аналитический инструмент уровня MVP (Minimum Viable Product) для исследования игровой экосистемы League of Legends на серверах Европы и США за май 2026 года. Проект успешно решает задачи автоматизации сбора сырых данных из внешнего API и их трансформации в готовые управленческие инсайты для геймдизайнеров, киберспортивных аналитиков и скаутов.

### Ключевая ценность разработанных модулей:

1. **Мониторинг вовлеченности (Раздел «Матчи»)**:
   * На основе метрик DAU и динамики ежедневной активности платформа позволяет издателю оценивать стабильность онлайна, удерживать аудиторию и анализировать влияние внутриигровых событий на вовлеченность игроков по регионам.
   * Интерактивный анализ общего баланса сторон (Win Rate Синей/Красной команды) предоставляет геймдизайнерам инструмент мгновенного контроля симметрии карты для исправления дисбаланса в будущих патчах.

2. **Профилирование игроков и скаутинг (Раздел «Игроки»)**:
   * Благодаря интеграции кастомных алгоритмов расчета среднего KDA и индекса агрессии игроков, дашборд позволяет киберспортивным тренерам категоризировать стили игры (плейстайл) игроков. Это упрощает поиск молодых талантов (High Elo) и выявление аномального поведения (токсичность/намеренный проигрыш).

3. **Анализ игровой меты и баланса (Раздел «Чемпионы»)**:
   * **Карта игровой меты** визуализирует корреляцию между популярностью чемпионов (`Pick Rate`) и их эффективностью (`Win Rate`) . Это главный инструмент для выявления несбалансированных (Overpowered) персонажей, требующих ослабления, а также «скрытой меты» — эффективных, но редких чемпионов в руках узкоспециализированных игроков .
   * **Кривая силы чемпионов** по времени игры математически разделяет персонажей на доминирующих в ранней игре (Early-game) и гипер-персонажей поздней стадии (Late-game scaling), помогая командам выстраивать победные стратегии на стадии драфта .
   * **Диаграмма распределения по позициям** наглядно демонстрирует профильные роли чемпионов и оценивает их «флекс-потенциал» (универсальность использования на разных линиях), что критически важно для тактического запутывания оппонента в матчах.

### Технический итог:
Проект демонстрирует высокий уровень оптимизации: тяжелые вычисления вынесены из памяти интерфейса Streamlit на сторону облачной СУБД Supabase (PostgreSQL) с помощью **SQL-витрин (Views)**. Продуманная система серверного кэширования гарантирует мгновенный отклик интерфейса для конечного пользователя, делая платформу масштабируемой и готовой к коммерческому использованию.
